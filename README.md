# Limbico
Límbico  Un asistente con memoria que vive en tu computadora.  Lo que hablas con él se guarda en tu equipo, cifrado con una contraseña tuya. No hay servidor, no hay cuenta y no hay nadie del otro lado leyendo nada.  Estado: BETA. Funciona y también se rompe. Se reparte por invitación mientras dure esta etapa.
